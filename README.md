# CampusConnect - Simple Version

A beginner-friendly Student Collaboration Platform using HTML, CSS, JavaScript and browser LocalStorage.

## Features
- Registration and login
- Dashboard
- Student profiles
- Skills
- Create projects
- Search projects
- Join projects
- Search students
- Logout
- LocalStorage data saving

## Run
1. Open this folder in VS Code.
2. Install the Live Server extension.
3. Right-click index.html.
4. Select Open with Live Server.
5. The site opens in your browser.

No Java, Maven, Spring Boot or MongoDB is required.
